## What pattern was added to my mental library?

* **Inheritance:** A child contract can reuse and extend functionality from a parent contract.
* **Interface:** Defines the functions needed to interact with an already deployed external contract without implementing its logic.
* **Oracle / Price Feed:** Provides external market data, such as ETH/USD prices, to smart contracts.
* **Decimal Conversion:** Different contracts may use different decimal precision, so values may need to be scaled before calculations.
* **Typecasting:** Converts a value from one Solidity data type to another, such as `int256` → `uint256`.

## Key takeaway

**A smart contract can use an interface + contract address to interact with an already deployed external contract and retrieve data such as ETH/USD prices. The returned value must be handled with the correct decimal precision and data type.**
