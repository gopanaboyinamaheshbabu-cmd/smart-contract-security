## What pattern was added to my mental library?

* **SafeMath:** A historical pattern used to protect arithmetic operations from overflow and underflow before Solidity 0.8.
* **Built-in Arithmetic Checks:** Solidity 0.8+ automatically reverts on overflow and underflow unless `unchecked` is used.
* **For Loop:** Used to repeatedly process elements in an array.
* **Array Reset:** `funders = new address[](0)` creates a new empty dynamic address array.
* **Array + Mapping Pattern:** The array tracks **who** funded, while the mapping tracks **how much** each address funded.
* **ETH Transfer with Call:** `call{value: amount}("")` sends native ETH from a contract and returns a success flag.
* **Safe Call Pattern:** Always check the returned `success` value and handle failure appropriately.
