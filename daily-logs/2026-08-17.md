## What pattern was added to my mental library?

* Deployment scripts make contracts **more flexible and reusable across different networks**.
* Fork tests allow us to test against **real blockchain state without deploying to the actual network**.
* `msg.sender` depends on **who directly calls the current contract**.
* `address(this)` refers to **the address of the current contract**.
* Good tests help identify problems caused by changes in the deployment architecture.
* Test coverage helps identify which parts of the code are **actually being tested**.
