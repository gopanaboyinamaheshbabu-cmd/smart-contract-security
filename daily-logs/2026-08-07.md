## What pattern was added to my mental library?

* **Interface:** Defines function signatures that allow a contract to interact with an already deployed contract.
* **Chainlink Data Feed:** Provides external price data such as ETH/USD to smart contracts.
* **`latestRoundData()`:** Used to retrieve the latest oracle price and related information.
* **Decimal normalization:** Different systems may use different decimal precisions, so values must be scaled before calculations.
* **Typecasting:** Converts compatible Solidity data types, such as `int256` to `uint256`.
* **Direct imports:** External Solidity interfaces can be imported through GitHub/NPM package paths.
* **Auditor mindset:** When a contract depends on an external oracle, always verify the address, returned data, decimals, and assumptions.
