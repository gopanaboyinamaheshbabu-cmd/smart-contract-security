## What pattern was added to my mental library?

* `constructor` → runs once during contract deployment.
* `msg.sender` in the constructor → identifies the account that deployed the contract.
* `modifier` → reusable condition for controlling function execution.
* `onlyOwner` → common access-control pattern.
* `constant` → value fixed at compile time.
* `immutable` → value fixed during deployment and cannot be changed afterward.
* Compile time → Solidity is converted into EVM bytecode.
* Deployment time → constructor executes and the contract is created.
* Runtime → users interact with the deployed contract.
