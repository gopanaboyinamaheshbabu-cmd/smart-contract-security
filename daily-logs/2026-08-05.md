## What pattern was added to my mental library?
- Factory Pattern: One contract can deploy and manage multiple instances of another contract.
- Contract Interaction: Contracts communicate using another contract's address and ABI.
- Inheritance: Child contracts reuse functionality from parent contracts.
- `virtual`: Allows a parent function to be overridden.
- `override`: Replaces the parent's implementation in the child contract.
