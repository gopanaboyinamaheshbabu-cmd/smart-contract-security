# 📝 Daily Log Format

Every learning day answers these five questions:

## ✅ What did I build today?
Projects, contracts, exercises, or features I implemented.

## ❌ What did I break today?
Compiler errors, bugs, failed experiments, or mistakes I fixed.

## 🔒 What vulnerability did I understand today?
Security concepts, attack vectors, exploits, or audit patterns.

## 📖 What production code did I read today?
OpenZeppelin, Solady, Solmate, Uniswap, Aave, MakerDAO, etc.

## 🧠 What pattern was added to my mental library?
New Solidity concepts, design patterns, best practices, or audit insights.
