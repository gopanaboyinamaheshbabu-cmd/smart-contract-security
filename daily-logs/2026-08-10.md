## What pattern was added to my mental library?

* `msg.sender`: The address that directly calls a smart contract function.
* Decimal Scaling: Solidity uses integer values, so values must be scaled using units such as `1e18`.
* Multiply Before Divide: Helps reduce precision loss caused by integer division.
* Library Pattern: Reusable Solidity functions can be placed in libraries.
* `using Library for Type`: Allows library functions to be called directly on a specific type.
* ERC-20 Pattern: Standard structure for fungible tokens using concepts such as balances, transfers, approvals, and allowances.
